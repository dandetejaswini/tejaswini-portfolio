# Dande Tejaswini - Portfolio Website

A modern, responsive portfolio website built with **React, Vite, and Tailwind CSS**, featuring an interactive AI assistant, custom avatar integration, project showcase, and a dedicated **Hire Tejaswini** action.

---

## Features

* **Interactive AI Assistant** – AI-powered assistant with quick response flows and custom avatar integration.
* **Hire Tejaswini** – Dedicated call-to-action for recruiters and potential clients.
* **Responsive Design** – Optimized for mobile, tablet, and desktop devices.
* **Modern UI** – Clean and professional interface with smooth interactions.
* **Project Showcase** – Highlights software development, AI, and web development projects.
* **Fast Performance** – Built with Vite for fast development and optimized production builds.
* **Social Links** – Direct access to GitHub and LinkedIn profiles.

---

## Tech Stack

* **Frontend:** React 18
* **Build Tool:** Vite
* **Styling:** Tailwind CSS
* **Icons:** Lucide React
* **Languages:** JavaScript, HTML, CSS
* **Version Control:** Git & GitHub

## Prerequisites

Before running the project, make sure you have:

* **Node.js** 16 or higher
* **npm**
* **Git**

Check your installed versions:

```bash
node --version
npm --version
git --version
```

---

## Local Setup

### 1. Clone the Repository

```bash
git clone https://github.com/dandetejaswini/dande-tejaswini-portfolio.git
```

### 2. Navigate to the Project

```bash
cd dande-tejaswini-portfolio
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open in Browser

Open:

```text
http://localhost:5173
```

---

## Build for Production

Create an optimized production build:

```bash
npm run build
```

The production files will be generated inside the `dist` directory.

### Preview Production Build

```bash
npm run preview
```
